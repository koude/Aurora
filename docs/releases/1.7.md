# Aurora 1.7

本版调整了首页配色：规则、全局、直连分别使用稳定的绿色、蓝色、黄色；连接控制恢复绿色和红色，并继续用“未连接／已连接”显示状态。

应用默认使用 Aurora 配色。Android 12 及以上可在“设置 → 常规”中选择“跟随壁纸配色”；这一选项不会改变首页代理模式的识别色。

首页顶部不再提供配置切换，配置仍可在设置中的“配置”页面管理。

## 下载

正式版提供 `arm64-v8a`、`armeabi-v7a`、`x86`、`x86_64` 和 `universal` 五种 APK。更新已安装应用时，请使用与原安装包签名一致的 APK。

本项目不提供代理节点或订阅服务。
