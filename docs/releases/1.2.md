# Aurora 1.2

Aurora 是基于 Clash Meta for Android 持续开发的 mihomo Android 客户端。本次正式版完善了项目与开源信息，调整了应用内“关于”页的排版，并精简公开仓库中不参与构建的历史文件；代理核心与 VPN 能力保持不变。

## 下载

本版提供五种 APK：

- `arm64-v8a`：64 位 ARM 设备。
- `armeabi-v7a`：32 位 ARM 设备。
- `x86`：32 位 x86 设备或模拟器。
- `x86_64`：64 位 x86 设备或模拟器。
- `universal`：包含以上架构；不确定设备架构时可选择此包。

更新已安装应用时，请使用与原安装包签名一致的 APK。本项目不提供代理节点或订阅服务。
