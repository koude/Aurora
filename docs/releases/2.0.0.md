# Aurora 2.0.0

本版在原有 VPN、代理服务之外新增透明代理（ROOT）模式。进入「设置 → 代理模式」可手动安装或卸载透明代理组件；首次使用需先安装并授予 ROOT 权限。卸载功能会清理 Aurora 在 ROOT 模式创建的运行文件和网络规则。透明代理模式仍需在已 ROOT 的设备上验证兼容性。

「设置 → 配置管理」新增“更新地理数据库与资源文件”，可在应用内更新地理与规则数据文件，不改动已导入配置中的规则或订阅。

修正透明代理模式下导入配置后策略组显示顺序与配置文件不一致的问题。

## 下载

正式版提供 `arm64-v8a`、`armeabi-v7a`、`x86`、`x86_64` 和 `universal` 五种 APK。更新已安装应用时，请使用与原安装包签名一致的 APK。

本项目不提供代理节点或订阅服务。
