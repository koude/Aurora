Aurora 1.0 是首个正式版。附件中的 APK 由本仓库的 GitHub Actions 使用固定签名构建，仅适用于 arm64-v8a 设备。

## 主要功能

- 首页、代理、连接、设置四个平级页面，重新打开后恢复上次所在页面。
- 从本地文件、订阅 URL、二维码导入配置；切换配置和更新订阅。
- VPN 自动接管或手动代理服务、分应用代理和网络设置。
- 策略组选择与测速、常用网站延迟检测、规则路由预判。
- 搜索活动连接；批量关闭时只处理当前筛选结果。
- Material 3 明暗色界面，兼顾大字体与系统手势区。

## 验证

- 发布前通过 76 项单元测试和 7 项 Android 虚拟机界面测试。
- 已在虚拟机导入并启用不含凭据的本地测试配置，启动 Android VPN，并检查路由预判与页面恢复。

## 范围与限制

- APK 仅包含 arm64-v8a，包名为 `com.koude.aurora`。
- 完整的 YAML／策略组编辑、MITM、实验性的隐藏应用图标功能不属于 1.0。
- 本地调试包不使用 GitHub 的签名密钥。更新已安装的 GitHub 版本时，请使用本页附件中的 APK。
