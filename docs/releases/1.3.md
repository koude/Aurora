# Aurora 1.3

本版重新组织首页：配置切换、当前出口模式和启动／停止集中展示；上下行速度与常用网站延迟归为一组，快捷工具独立成组。模式图标使用更容易辨认的分流、直连与全局符号，启动和停止按钮分别使用绿色与红色。全局主题色暂未调整。

代理页的策略组标题改为双行，最终出口获得完整的一行宽度。连接页卡片也更紧凑，显示规则、出口和实时上下行速度，不再显示无法准确识别的应用来源。

## 下载

正式版提供 `arm64-v8a`、`armeabi-v7a`、`x86`、`x86_64` 和 `universal` 五种 APK。更新已安装应用时，请使用与原安装包签名一致的 APK。

本项目不提供代理节点或订阅服务。
