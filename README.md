# Aurora

Aurora 是一款原生 Android 代理客户端，提供清晰的配置管理、代理选择与网络状态查看。

## 下载与安装

从 [GitHub Releases](https://github.com/koude/Aurora/releases) 下载 APK。当前提供适用于 64 位 ARM 设备的版本，支持 Android 5.0 及以上系统。

使用前需自行导入本地配置或远程订阅；项目不提供代理节点或订阅服务。

## 主要功能

- Android VPN 与本地代理服务两种接入方式
- 配置导入、订阅更新与配置切换
- 策略组和节点选择、延迟测试、连接查看与关闭
- 分应用代理、网络与高级设置
- 网站连通性检测与路由预判

部分功能的可用性取决于配置文件、Android 版本与设备环境。
